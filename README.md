# Validator CNP (Cod Numeric Personal) 🇷🇴

Un utilitar web simplu, rapid și sigur pentru validarea Codului Numeric Personal românesc, construit pentru a rula exclusiv în browser.

## 🚀 Funcționalități
* **Validare matematică:** Folosește algoritmul oficial (cifra de control modulo 11) pentru a verifica autenticitatea CNP-ului.
* **Extragere date:** Dacă codul este valid, instrumentul decodifică data nașterii, sexul și județul.
* **100% Sigur (Client-Side):** Nu există o bază de date sau un backend. Datele introduse nu părăsesc niciodată browser-ul utilizatorului, respectând complet confidențialitatea.

## 🛠️ Tehnologii folosite
* HTML5
* CSS3
* JavaScript (Vanilla)
